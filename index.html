●　FINAL YEAR PROJECT / 202601 — 04

ASD early detection
with explainable AI

A multi-age screening prototype for infants, children, and teens.

PythonFastAPIReactMongoDBYOLOv8SHAP
i

Screening support, not diagnosis. This academic prototype surfaces patterns for review; it is not a substitute for assessment by a qualified clinician.

THE CHALLENGE

Early behavioral signals look different at different ages. This project brings age-specific assessments into one workflow and adds a view of which inputs influenced each model output.

THREE PATHS, ONE SYSTEM
A / 0—3

Infants

YOLOv8, MediaPipe, and OpenCV support face and eye tracking. The module measures gaze stability, fixation and attention duration, gaze deviation, and head movement.

VIDEO → GAZE FEATURES
B / 4—12

Children

Questionnaire data is prepared with KNN imputation and Isolation Forest, then classified with Random Forest and XGBoost models. SHAP highlights influential responses.

ANSWERS → BEHAVIORAL PROFILE
C / 13—17

Teens

Reaction-time and emotion-recognition games produce accuracy, decision, attention, and impulse-related features for age-wise classification.

GAME EVENTS → RESPONSE FEATURES
HOW A RESULT IS FORMED
01Choose age group→02Capture input→03Extract features→04Classify & explain→05Review with context
✳

Why explainability matters
SHAP summaries show which questionnaire or behavioral features pushed a prediction toward or away from a risk class. That makes an output easier to inspect than a score alone.

Next steps in the project deck: explore personalized support recommendations and a lightweight mobile screening experience.
